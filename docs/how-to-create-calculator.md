# Como Criar Uma Calculadora

1. Adicione a definição no `CalculatorCatalogService`.
2. Crie ou ajuste o cálculo no `CalculatorApplicationService`.
3. Garanta saída com `CalculationResult` e `CalculationLineItem`.
4. Adicione validações com FluentValidation quando necessário.
5. Crie testes unitários para regra, arredondamento e limites.
6. Verifique a página em `/calculadoras/{slug}`.

Toda calculadora deve ter extrato, explicação simples, FAQ e aviso legal.
